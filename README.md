## Featured projects

### 🔩 Automatic screw sorter — vision-based clustering
*Engineering school project, team of 5 (2025–2026)* · [Repository](https://github.com/gtritzguden/REPO_NAME)

A 3D printer converted into an automatic sorter for screws, nuts and washers (1,000 parts, 5 classes).

- My part: printer control algorithm, classification pipeline (from **OpenCV** prototypes to DINOv2), and the full project documentation

`Python` `PyTorch` `DINOv2` `OpenCV` `scikit-learn`
